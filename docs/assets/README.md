# Tempo graphics

All original Tempo icons, SVGs, README graphics, store composites, and social images are MIT licensed. Bundled fonts retain their [SIL OFL notice](../../extension/fonts/OFL.txt). The popup captures show the real extension UI; surrounding layout/copy is promotional artwork.

| Asset | Purpose |
| --- | --- |
| [hero-light.png](hero-light.png) / [hero-dark.png](hero-dark.png) | README cover graphics with real light/dark popup captures. |
| [install-button.svg](install-button.svg) | Local README Store install button. |
| [window-scope.svg](window-scope.svg) | Explain that a timer affects only its chosen window. |
| [tempo-social-1200x630.png](tempo-social-1200x630.png) | Social-media link card; ready to share. |
| [Store screenshots](../../store/screenshot-light-1280x800.png) / [dark version](../../store/screenshot-dark-1280x800.png) | 1280 × 800 Chrome Web Store assets. |
| [Promotional tile](../../store/promo-440x280.png) | 440 × 280 Store tile. |
| [Original icons](../../extension/icons/icon-128.png) | Also available at 16, 32, and 48 px in the runtime. |

Regenerate by running the browser suite, then `npm run assets:store` and `npm run assets:readme`. Icon regeneration uses `scripts/assets.py`. See [development](../DEVELOPMENT.md) for prerequisites. Rendering source for every graphic is included in the repository.
